# Jhon Eric Baler Salinas – Personal Portfolio

Modern dark-themed personal portfolio built with **React + TypeScript + Vite**.

## Features
- Clean corporate dark theme (black + blue)
- Fully responsive
- Sections: Hero, About, Skills, Experience, Projects, Education & Certifications, Contact
- Resume / CV download button
- Social links (LinkedIn, Facebook, Instagram)
- Mobile-friendly navigation

## Getting Started

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build for Production

```bash
npm run build
npm run preview
```

## Customization
- Profile picture: replace the avatar placeholder in `src/App.tsx` (search for `avatar-placeholder`)
- Resume: replace `public/Jhon_Eric_Salinas_Resume.pdf`
- Colors: edit CSS variables in `src/index.css`
